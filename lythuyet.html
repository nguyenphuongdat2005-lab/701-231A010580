Lưu ý: Nội dung dưới đây là ví dụ minh họa. Hãy sửa câu hỏi và câu trả lời theo đúng phần Lý thuyết trong đề của giảng viên.

Câu 1: HTML là gì?

HTML (HyperText Markup Language) là ngôn ngữ đánh dấu được sử dụng để xây dựng cấu trúc và nội dung của trang web.

Câu 2: CSS là gì?

CSS (Cascading Style Sheets) là ngôn ngữ định dạng, giúp thiết lập màu sắc, phông chữ, khoảng cách và bố cục của trang web.

Câu 3: JavaScript dùng để làm gì?

JavaScript là ngôn ngữ lập trình thường dùng để tạo tương tác và xử lý hành động của người dùng trên trang web.

Câu 4: Thẻ liên kết trong HTML là thẻ nào?

Thẻ <a> tạo liên kết. Thuộc tính href xác định địa chỉ trang đích, ví dụ <a href="index.html">Trang chủ</a>.

Câu 5: Cách chèn hình ảnh vào HTML?

Dùng thẻ <img> với thuộc tính src để chỉ đường dẫn ảnh và alt để mô tả ảnh, ví dụ <img src="images/avatar.jpg" alt="Ảnh đại diện">.
