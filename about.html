Phần Lý Thuyết & Giải Thích Chi Tiết

Câu 1: Trình bày vai trò của HTML, CSS và JavaScript trong việc phát triển một trang web?

Trả lời & Giải thích:

  • HTML (HyperText Markup Language): Đóng vai trò là bộ khung xương, định nghĩa cấu trúc và các thành phần nội dung trên trang web (văn bản, hình ảnh, tiêu đề, bảng biểu, form...).
  • CSS (Cascading Style Sheets): Đóng vai trò tạo kiểu và giao diện (styling), quyết định màu sắc, font chữ, bố cục (layout), khoảng cách và tính đáp ứng (responsive) trên các thiết bị khác nhau.
  • JavaScript: Đóng vai trò tạo tính năng tương tác động (behavior), xử lý sự kiện người dùng (click, hover), tương tác với API, kiểm tra dữ liệu form và cập nhật nội dung trang web mà không cần tải lại trang.

Câu 2: GitHub Pages là gì và lợi ích của việc sử dụng GitHub Pages để deploy website tĩnh?

Trả lời & Giải thích:

  • Khái niệm: GitHub Pages là một dịch vụ lưu trữ (hosting) mã nguồn mở miễn phí do GitHub cung cấp, cho phép xuất bản các trang web trực tiếp từ một kho lưu trữ (repository) trên GitHub.
  • Lợi ích: Hoàn toàn miễn phí, tốc độ truy cập nhanh, tích hợp liền mạch với hệ thống quản lý mã nguồn Git, tự động hỗ trợ chứng chỉ bảo mật SSL (HTTPS) và dễ dàng cấu hình domain cá nhân.
